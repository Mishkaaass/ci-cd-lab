KUBERNETES / GITOPS

Inspect desired state and drift.

Requires the dedicated kind cluster and pinned kubeconfig.

bash scripts/gitops-demo.sh doctor
bash scripts/gitops-demo.sh status
bash scripts/gitops-demo.sh drift-test

Drift test temporarily changes replica count, then verifies Argo CD reconciliation.

Why are there two paths?

They solve different problems. Docker demonstrates the mechanics of safe traffic promotion and rollback; GitOps demonstrates declarative control of an independent cluster. The console observes both without combining their permissions.

What this lab does not claim

No public-cloud deployment, enterprise SSO, managed backup or automatic GitOps image promotion. A bound PVC is persistent storage, not a verified backup.
